AI Web Translator 设置

所有设置仅保存在本机扩展存储（chrome.storage.local）中。 点击“翻译当前网页”后，页面中允许翻译的正文文本会发送给 DeepSeek API （不含 URL、标题、表单、密码、Cookie）。未点击翻译时不会发送任何数据。

Translation Provider

V1 默认使用 DeepSeek；其他 Provider（OpenAI / Gemini / Claude / DeepL 等）将在后续版本开放。

DeepSeek API Key

未配置

Key 只保存在本机扩展存储中，保存后不再回显，也不会打印到 Console 或日志。 注意：chrome.storage.local 对个人自用方便，但它不是强加密保险箱，请勿在共享设备上保存。

Model

网页翻译优先考虑速度与成本，默认 Flash；Pro 质量更高但更慢。

高级设置

V1 DeepSeek Provider 固定使用官方端点 https://api.deepseek.com/chat/completions，不能修改为任意服务器；自定义 Endpoint 将在 Custom OpenAI-Compatible Provider 中提供，且不会因此增加任何新的 host 权限。
